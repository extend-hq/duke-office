# Repository instructions

- Never mention any specific customers, files, or examples in comments.
- Do not copy third-party package implementation code into the workspace crates. Do not disguise copying through renaming, reformatting, or mechanical translation.
- Implement functionality from format specifications and documented behavior. Reuse external implementations through declared dependencies.
- Preserve attribution, provenance, and license notices for bundled third-party data and assets. Identify these separately from implementation code when reporting source audits.
- Describe source-comparison coverage and limitations accurately; a clean comparison against a finite corpus does not prove universal originality.
