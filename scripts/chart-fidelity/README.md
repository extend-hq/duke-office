# Compare Office Charts with desktop Excel

This benchmark compares the opt-in full browser renderer directly with independently exported Excel chart pictures. It never invokes another viewer as a fallback. Python 3.11+, Pillow, NumPy, Node, Playwright Core, and Chromium are required for the benchmark only. No benchmark dependency is part of the chart library.

1. Run `python3 scripts/chart-fidelity/extract.py --out target/chart-fidelity PATH...`. Each path is an XLSX workbook or a directory of workbooks. Identical workbook bytes are counted once; a split sheet saved as a different workbook remains a separate input. The extractor traverses package relationships, including chartsheets and ChartEx graphic frames. It includes the workbook font and theme, chart styles, and color parts. For an omitted cache it resolves a single-cell or rectangular A1 reference, including workbook-scoped defined names, using stored worksheet values. It does not recalculate formulas or reproduce Excel's filter state; unresolved references are listed in the report.
2. Export native charts from the same workbook versions. On macOS with Excel installed, see [the capture helper](native/capture.py). A reference manifest is a JSON array with `workbookSha256`, `sheet`, `name`, and `png` (relative to that manifest or absolute). A `part` path can disambiguate the chart object. When the same object name occurs multiple times on a sheet, provide its verified one-based `chartOrdinal`; otherwise the ambiguous capture is skipped. Supply the native `widthPt`, `heightPt`, and export `dpi` where possible; absent object dimensions use the PNG dimensions and specified DPI, defaulting to 72. Match a workbook by its full SHA-256; a similarly named workbook is insufficient. For exports made from a derived workbook, set `derived: true`, `derivedSha256` and a human-readable `source` describing the transformation. Keep the original digest and chart identity as the join keys. The report separates direct and derived captures. If native capture fails, a manifest row may specify `unavailable` with its observed reason instead of `png`; this keeps the chart visible and unscored.
3. Run `python3 scripts/chart-fidelity/compare.py prepare target/chart-fidelity --references MANIFEST...`. Later manifests take precedence for the same identity. Omitting a manifest measures rendering coverage without claiming visual parity.
4. Run `node scripts/chart-fidelity/render.mjs target/chart-fidelity target/chart-fidelity/candidate`. For a before/after comparison, run once per renderer revision into different output directories, using the same prepared jobs. A third argument can point to another full browser entry with its adjacent generated binary. Set `CHART_FIDELITY_PLAYWRIGHT` to the installed Playwright Core package path and `CHART_FIDELITY_CHROMIUM` to a Chromium executable if they are not discoverable by default.
5. Run `python3 scripts/chart-fidelity/compare.py report target/chart-fidelity --run target/chart-fidelity/candidate` and open the resulting `report.html`. Use `--baseline path/to/previous/report.json` to add before/after metrics. Each paired chart includes a wipe slider, difference heatmap, exact pixel mask and native-PDF label token comparison when extractable. For PDF text diagnostics, install Poppler’s `pdftotext`. The sibling JSON retains per-chart metrics and errors, source series targets, the runner's Chromium version, and WASM digest. The report refuses a render made against a different job manifest.

The candidate uses the actual browser WASM. Chromium rasterizes the returned SVG in a sandboxed document on a white background at the export scale. The chart object size and the exported canvas can differ slightly because Excel pads some exported pictures. No translation search or nonuniform rescaling is used. Without a native reference, one-cell and absolute anchors supply the preview size when available; otherwise the preview is 640 × 360. Fonts and platform antialiasing affect pixels. “Exact” means every composited RGB pixel of that export matches. The report does not certify live selection, edit handling, or workbooks outside the corpus.

The native capture helper opens uniquely named read-only temporary copies and requests closure without saving. Some Excel versions acknowledge that request while leaving the workbook open. The helper verifies closure and stops if the copy remains open; close the named temporary copy without saving before resuming. Existing reference images remain usable, and the original workbooks are never modified.

Set `CHART_FIDELITY_FONTS` to a local JSON array of `{family, weight, style, path}` entries to isolate rendering differences from font substitution. The rasterizer registers these faces temporarily in a sandboxed document, blocks network access, and records font digests without copying or redistributing the fonts. The host application still needs its own fonts. With no manifest, Chromium uses the platform fonts available to it.

Use `python3 scripts/chart-fidelity/docx/compare.py --base <revision> --out <results> <document.docx> [...]` to compare DOCX chart images, sources, semantic data and figure references. This guard exits nonzero on changes or an empty baseline corpus.

Run `node scripts/chart-fidelity/interaction.mjs target/chart-fidelity` to validate the full corpus's source series and point identities, send trusted browser pointer events to reachable marks and legends, and compare interactive/static raster pixels. It accepts the same Playwright and Chromium environment variables and writes `interaction.json` with the exact tested WASM and corpus digests. Invalid identities, click mismatches, and altered pixels fail the check. Unrendered inputs, charts with no plotted marks, and occluded series are reported separately. The host viewer's selection state, handles, formula editing, and resize behavior require a mounted viewer check.
